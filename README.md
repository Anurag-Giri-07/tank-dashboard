# Tank level dashboard

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually `http://localhost:5173`).

## Checks

- Current level is 55%, the minimum is 18%, and the maximum is 78%.
- The tank bar is green at 55%.
- The earlier-low-level list includes the 16:00 reading at 18%.
- Run `npm test` to test the calculation logic and `npm run build` for a production build.
